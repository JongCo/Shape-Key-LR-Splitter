# Shape Key L/R Splitter

중앙의 전환 폭을 조절해 하나의 셰이프 키를 좌우 키로 나누는 Blender 애드온입니다. Blender 3.6 이상을 대상으로 합니다.

## 설치

1. Blender의 **Edit → Preferences → Add-ons**에서 **Install...**을 선택합니다. Blender 버전에 따라 **Install from Disk...** 메뉴를 사용합니다.
2. `shape_key_lr_splitter.py`를 선택하고 애드온을 활성화합니다.

## 사용

1. 메시 오브젝트를 선택하고 Object Mode로 전환합니다.
2. Object Data Properties의 Shape Keys에서 분리할 키를 선택합니다. Basis는 선택할 수 없습니다.
3. 3D View에서 `N`을 눌러 사이드바를 열고 **Shape Key Splitter** 탭을 선택합니다.
4. **Transition Width**로 중앙 전환 구간의 전체 너비를 조절합니다. Basis 메시의 로컬 X축 전체 너비에 대한 백분율입니다. 예를 들어 메시가 X축으로 2m이고 설정값이 20%이면 전환 구간은 0.4m입니다.
5. 필요하면 **Center X**로 전환 구간의 중심을 오브젝트의 로컬 좌표 기준으로 옮깁니다. 기본값은 0입니다.
6. **Split Active Shape Key**를 누르면 기존 키를 유지하면서 `원본이름.L`과 `원본이름.R` 키를 생성합니다. 이미 같은 이름이 있으면 Blender가 이름에 번호를 붙입니다.

생성된 키는 값이 0인 상태로 추가됩니다. 결과를 확인할 때는 원본 키의 값을 0으로 만들고, 좌우 키의 값을 각각 조절하세요. 두 키를 같은 값으로 설정하면 원본 키를 그 값으로 설정한 것과 같은 변형이 됩니다. 원본을 함께 켜면 변형이 중복 적용됩니다.

## 동작 방식과 제한

- `.L`은 로컬 **+X**, `.R`은 로컬 **−X** 영역입니다. 오브젝트의 회전이나 월드 위치와는 무관합니다.
- 전환 구간 바깥에서는 각 측면의 변형이 온전히 유지되고, 구간 안에서는 부드러운 곡선으로 가중치가 바뀝니다. 양쪽 가중치의 합은 항상 1입니다. 폭이 0이면 중심에서 정확히 나누며 중심에 놓인 버텍스는 양쪽에 절반씩 배분합니다.
- 분리 위치는 변형된 얼굴이 아닌 Basis 메시의 버텍스 위치를 기준으로 계산합니다. 메시가 중심에서 벗어나 있다면 Center X를 조정하세요.
- 상대 셰이프 키만 지원합니다. 원본의 상대 키와 버텍스 그룹, 슬라이더 범위를 유지합니다.
- 설정을 바꾼 후 다시 생성하면 새 키가 추가됩니다. 기존에 생성된 키는 자동으로 변경되지 않습니다.
